手機測試入口：[開啟 M1 預覽](https://conyku0508.github.io/song-merchant-life-test/?release=20261026-m1)。請將手機橫放；直式顯示旋轉提示。

這是 2026-10-26 的 M1 介面原型：43 個獨立畫面、人物分頁／頁籤、導覽與返回、暫停、確認及大字模式。尚未接入真實經濟、出航、人物關係或存讀檔。所有數值及共用概念肖像均為預覽。

`site.part-*.b64` 為 ZIP 發布包的 Base64 分段，還原後保留原型的獨立 `ui/`、`application/`、`logic/`、`fixtures/`、`contracts/` 與 `assets/`，未將不同畫面或資料合併成單一實作。ZIP 內有 186 個執行資源的 SHA-256 清單。GitHub Actions 會解壓縮、驗證清單後部署到 Pages。

本機已通過 7 項單元測試；740×360、844×390、932×430 與兩種字級共 252 組畫面量測已完成。手機實機的安全區、工具列、旋轉與觸控仍待驗收。十業種、物流、人事、官府、委任、生活家庭、走私暗殺、災害、人物生命與結局的完整目標均保留於後續階段。

更新測試版：更新 `site.part-*.b64` 各分段，提交訊息包含 `Publish M1`，或從 Actions 手動執行部署。這個儲存庫只作獨立手機測試，不修改其他遊戲專案。
