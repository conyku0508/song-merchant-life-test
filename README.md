# 天下豪商

北宋水滸背景、手機橫式的商人生涯策略遊戲，以《天下御免》的完整玩法架構分期開發。

本輪已將介紹人、15位原創NPC候選、職類試藝與音效接入正式人事、費用及月薪。開張指引能帶玩家從組班底、任命掌櫃、造船、許可走到第一趟貨物入庫；108位水滸人物依事件、生意線索與相識逐步登場。整體玩法尚未全部完成，不宣稱精確復刻原作公式。
